# 提示詞

通話中 Bageo 交代 AI 的話是內建在 Bageo 裡的。在這裡放一個檔，就能改寫其中幾段，不用等新版 Bageo：這個資料庫下一次發佈之後，主人在控制台按「檢查更新」，Bageo 就會下載改過的文字，下一通電話起使用。

English: [README.md](README.md).

## 改一段文字

1. 到 `bageo-call` 的 `crates/agent/data/prompts/<語言>.json` 找到那段文字，記下它的 key。語言有 `zh-TW`、`en`、`ja`、`ko`、`es`、`fr`、`de`、`pt`；簡體中文跟著 `zh-TW`。
2. 在這裡新增或修改 `prompts/<語言>.json`，只放要改的那幾段：

   ```json
   {
     "format": 1,
     "lang": "zh-TW",
     "texts": {
       "kick_resume": "這段文字的新寫法。"
     }
   }
   ```

   一段文字可以是一個字串，也可以是一行一行的清單。
3. 送出 Pull Request。有問題的話，檢查流程會用白話說明哪裡不對。
4. 合併之後，由維護者推送發佈用的 tag（`vYYYYMMDDNN`）。

想改回內建的文字，把那段從檔案裡刪掉、再發佈一次就好。

## 檢查會看的規則

- key 必須是 Bageo 在那個語言裡有的。
- 內建文字裡的每個 `{佔位符}` 都要保留，也不能多加。
- 開頭和結尾的空白與換行要跟內建的一樣。
- 長度最多是內建文字的兩倍，或多 400 個字。
- 不能有控制字元、方向控制字元或看不見的字元。
- 鎖定的文字不能在這裡改。它們是 Bageo 一定要守的規則，例如不給個資、被認真問時承認是 AI；只有新版 Bageo 才會改。內建檔的 `"locked"` 列出了是哪幾段。

寫處境、大概方向和底線就好，不要寫要 AI 照唸的台詞。文字是給所有來電用的：不要放真實的姓名、電話或地址。
